# Portfolio Test

Next.js frontend with a Flask backend for a portfolio chat guide.

## Stack

- Frontend: Next.js 14
- Backend: Flask
- AI SDK: `google-genai`

## Environment files

## Local run

### Frontend

```bash
npm run dev
```

### Backend

```bash
backend\.venv\Scripts\python.exe backend\app.py
```
